## 1. Connexion à l'espace

1. Ouvrez votre navigateur (Chrome, Firefox, Safari…)
2. Accédez à l'adresse du portail communiquée par l'administration
3. Saisissez votre **adresse e-mail** et votre **mot de passe**
4. Cliquez sur **Se connecter**

> 💡 **Mot de passe oublié ?** Contactez la secrétariat qui peut réinitialiser votre accès.

---

## 2. Tableau de bord — Vue d'ensemble

Dès la connexion, vous arrivez sur votre **tableau de bord personnel** qui affiche :

| Indicateur | Description |
|---|---|
| **Documents administratifs en attente** | Nombre de demandes de documents que vous avez soumises et qui attendent traitement |
| **Autres demandes en attente** | Vos demandes diverses (photocopie, salle, etc.) + congés en cours de traitement |
| **Congés pris (année en cours)** | Total des jours de congé approuvés depuis le 1er janvier |
| **Absences (année en cours)** | Nombre d'absences enregistrées cette année |

En dessous des statistiques, deux tableaux s'affichent :
- **Mes documents administratifs** — les demandes récentes (en attente ou approuvées)
- **Mes autres demandes** — photocopies, salles, etc.

## 3. Mon dossier employé

Pour consulter votre fiche personnelle :

1. Dans le menu de gauche, cliquez sur **Dossiers Employés**
2. Votre fiche s'ouvre automatiquement (vous ne voyez que la vôtre)

Vous pouvez consulter :
- Vos informations personnelles (nom, CIN, CNSS, coordonnées…)
- Votre contrat et poste
- Vos **documents** (CIN scan, diplôme, contrat, etc.)

### Mettre à jour une information

Certains champs peuvent être modifiés directement (ex. : téléphone, adresse). D'autres sont réservés à l'administration (contrat, salaire).

1. Cliquez sur **Modifier** (crayon en haut à droite)
2. Remplissez les champs souhaités
3. Cliquez sur **Enregistrer**

> ⚠️ Les champs grisés ne sont pas modifiables — contactez la secrétariat si une correction est nécessaire.

## 4. Demander un document administratif

Un **document administratif** est un document officiel produit par l'établissement : attestation de travail, bulletin de paie, etc.

### Étapes

1. Menu de gauche → **Mes documents** (groupe *Mes demandes*)
2. Cliquez sur **+ Créer**
3. Remplissez le formulaire :

| Champ | Description |
|---|---|
| **Type de document** | Choisissez dans la liste |
| **Format** | Digital (envoi par email) ou Papier (remis en main propre) |
| **Nombre d'exemplaires** | Si format papier |
| **Description / détails** | Précisez l'utilisation ou toute information utile *(obligatoire)* |

4. Cliquez sur **Créer**

### Types de documents disponibles

| Code | Document |
|---|---|
| Attestation de travail | Confirme votre emploi dans l'établissement |
| Attestation de salaire | Mentionne votre rémunération |
| Bulletin de paie | Détail mensuel de votre salaire |
| Attestation IR | Pour déclaration fiscale |
| Crédit irrévocable | Pour dossier bancaire |
| Attestation CNSS | Couverture sociale |
| Ordre de mission | Déplacement professionnel |
| Certificat de travail | En cas de départ |

### Récupérer votre document

- Une fois la demande **Approuvée**, un fichier sera joint
- Cliquez sur **Télécharger document** dans la liste ou sur la fiche de la demande

## 5. Déclarer une absence ou un congé

1. Menu de gauche → **Demandes d'absences** (groupe *Mes demandes*)
2. Cliquez sur **+ Créer**
3. Remplissez le formulaire :

### Champs communs

| Champ | Description |
|---|---|
| **Catégorie** | **Congé** (planifié) ou **Absence** (imprévu, maladie…) |
| **Date de début** | Premier jour concerné |
| **Date de fin** | Dernier jour concerné |
| **Description / détails** | Motif ou précisions *(obligatoire)* |

### Champs spécifiques aux congés

| Champ | Description |
|---|---|
| **Type de congé** | Annuel, Maladie, Maternité, Sans solde |
| **Remplaçant(e)** | Enseignant(e) qui assurera vos cours (optionnel) |
| **Pièce jointe** | Certificat médical ou autre justificatif |

### États possibles

| Statut | Signification |
|---|---|
| 🟡 **En attente** | Soumise, en cours d'examen |
| 🟢 **Approuvée** | Validée par la direction |
| 🔴 **Refusée** | Non accordée — consultez la description pour le motif |

> ⚠️ Vous pouvez **modifier une demande en attente** mais plus une fois traitée.

## 6. Autres demandes

Les autres demandes regroupent toutes les sollicitations opérationnelles du quotidien.

1. Menu de gauche → **Mes autres demandes** (groupe *Mes demandes*)
2. Cliquez sur **+ Créer**
3. Choisissez le **Type de demande**

---

### 6.1 Photocopie

Demande de reproduction de documents pour vos classes.

#### Champs à remplir

| Champ | Description |
|---|---|
| **Nature du document** | Ex : Examen, Contrôle continu, Contrôle d'essai, Cours, Exercices… |
| **Niveau** | Niveau scolaire concerné (ex : 1ère Année du primaire) |
| **Groupe / Classe** | La classe concernée |
| **Nombre de copies souhaitées** | Nombre total de photocopies |
| **Date souhaitée** | Date à laquelle vous souhaitez récupérer les copies |
| **Description / détails** | Précisions éventuelles *(obligatoire)* |

#### Règles importantes

> 📅 **Délai minimum : 3 jours ouvrés à l'avance** (week-ends non comptés)
>
> Exemple : si vous soumettez le **vendredi**, la date la plus proche disponible est le **mardi** suivant.

> 🚫 **Niveau Primaire — 1 évaluation par classe par jour :**
> Pour les groupes du primaire, il n'est pas possible de planifier deux évaluations (Examen / Contrôle continu / Contrôle d'essai) pour la même classe le même jour. Si un conflit existe, un message d'erreur rouge vous indique la nature déjà planifiée et vous demande de choisir une autre date.

## 7. Suivre l'état de mes demandes

### Depuis le tableau de bord

Les tableaux en bas de la page d'accueil affichent vos **5 demandes les plus récentes** (en attente ou approuvées).

### Depuis les menus

Accédez à **Mes documents** ou **Mes autres demandes** pour voir l'historique complet avec les statuts.

### Codes couleur des statuts

| Badge | Couleur | Signification |
|---|---|---|
| **En attente** | 🟡 Jaune | Demande soumise, pas encore traitée |
| **Approuvé** | 🟢 Vert | Demande acceptée et traitée |
| **Refusé** | 🔴 Rouge | Demande non accordée |

## 8. Questions fréquentes

**Q : Je ne trouve pas le type de document dont j'ai besoin ?**
> Utilisez le type **Divers** et précisez dans la description.

**Q : Je me suis trompé dans ma demande, comment corriger ?**
> Tant que le statut est **En attente**, cliquez sur la demande → **Modifier**. Une fois traitée, il n'est plus possible de la modifier — créez une nouvelle demande si nécessaire.

**Q : Ma demande de photocopie est bloquée avec un message d'erreur rouge ?**
> Pour les classes du primaire, une seule évaluation (Examen/Contrôle) est autorisée par classe par jour. Choisissez une autre date disponible.

**Q : Je n'arrive pas à me connecter ?**
> Vérifiez que vous utilisez la bonne adresse e-mail. Si le problème persiste, contactez la secrétariat pour réinitialiser votre mot de passe.

**Q : Où télécharger mon document une fois approuvé ?**
> Dans **Mes documents** → cliquez sur la demande → bouton **Télécharger document** (disponible uniquement si le statut est *Approuvé* et qu'un fichier a été joint).

**Q : Puis-je supprimer une demande ?**
> Non, vous ne pouvez pas supprimer vos demandes. Vous pouvez les modifier tant qu'elles sont en attente.
