1
Réinitialiser votre mot de passe
Vous avez reçu un email pour créer votre mot de passe ou vous l'avez oublié
1
Accéder à la page de connexion
Ouvrez votre navigateur et accédez à l'adresse de l'application fournie par votre administration. Sur la page de connexion, cliquez sur "Mot de passe oublié ?".
Page "Mot de passe oublié" — Espace Perso
2
Saisir votre adresse email
Entrez votre adresse email professionnelle dans le champ prévu, puis cliquez sur "Envoyer l'email". Un message de confirmation s'affichera à l'écran.
ⓘ
Important : Utilisez l'adresse email que votre administration a enregistrée pour vous (ex : prenom.nom@lesecolesalbaraime.com).
3
Vérifier votre boîte mail et cliquer sur le lien
Ouvrez votre messagerie. Vous recevrez un email de Les Ecoles AL BARAIME avec le sujet "Réinitialisation de votre mot de passe". Cliquez sur le bouton "Réinitialiser mon mot de passe".
Email reçu dans la boîte mail avec le lien de réinitialisation
⚠
Attention : Ce lien expire dans 60 minutes. Si vous ne l'utilisez pas à temps, recommencez la procédure depuis l'étape 1.
4
Créer votre nouveau mot de passe
Une page s'ouvre dans votre navigateur. Entrez un nouveau mot de passe (minimum 8 caractères, avec des lettres et des chiffres), confirmez-le, puis cliquez sur "Réinitialiser le mot de passe". Vous serez redirigé automatiquement vers votre espace.
🔒
Choisissez un mot de passe que vous pouvez retenir facilement mais que les autres ne peuvent pas deviner. Exemple : Yasmine2026!
2
Le Tableau de bord
La première page que vous voyez après connexion
1
Se connecter
Sur la page de connexion, entrez votre adresse email et votre mot de passe, puis cliquez sur "Se connecter". Vous arrivez sur votre tableau de bord personnel.
2
Découvrir le tableau de bord
Le tableau de bord affiche un résumé de votre situation en temps réel :
Vue du tableau de bord après connexion
Indicateur Description
Documents administratifs en attente Nombre de demandes de documents en cours de traitement
Autres demandes en attente Demandes de photocopies, matériel, grande salle...
Congés pris (année en cours) Nombre de jours de congés approuvés cette année
Absences (année en cours) Nombre d'absences enregistrées cette année
3
Naviguer dans le menu
Le menu à gauche contient toutes vos fonctionnalités :
  • Tableau de bord — Retour à l'accueil
  • Mon profil — Vos informations personnelles
  • Demandes d'absence — Créer et suivre vos absences
  • Mes documents — Demander des documents administratifs
  • Mes autres demandes — Photocopies, matériel, grande salle...
3
Mon profil
Consulter vos informations, les modifier et gérer vos documents personnels
1
Consulter votre dossier — Onglet Identité
Cliquez sur "Mon profil" dans le menu gauche. Votre fiche complète s'affiche avec votre nom, poste, matricule et statut (CDI, Actif...). L'onglet "Identité" est ouvert par défaut : vous y trouvez vos informations civiles (CIN, CNSS, date de naissance, diplôme...).
Dossier employé — Onglet Identité
👁
Vous pouvez naviguer entre les onglets : Identité, Coordonnées, Situation familiale, Poste & Contrat, Documents, Accidents de travail, Fondation M6, Crédits.
2
Modifier vos informations
Cliquez sur le bouton "Modifier" en haut à droite de votre fiche. Vous pouvez mettre à jour vos coordonnées, adresse, téléphone, etc. Une fois les modifications faites, cliquez sur "Sauvegarder les modifications".
Formulaire de modification du dossier employé
Ajouter un document personnel
3
Uploader un document (CIN, RIB, Diplôme...)
Dans le formulaire de modification, faites défiler vers le bas jusqu'à la section Documents. Cliquez sur "Ajouter un document". Une fenêtre s'ouvre :
  • Choisissez le type de document (Photo, CIN scan, Extrait de naissance, Carte CNSS, RIB scan, Diplôme, Contrat ANAPEC, Autre)
  • Faites glisser votre fichier ou cliquez sur "Parcourir"
  • Cliquez sur "Créer"
Fenêtre d'ajout de document personnel
Déclarer un accident de travail
4
Signaler un accident
Faites défiler jusqu'à l'onglet "Accidents de travail" dans le formulaire de modification, puis cliquez sur "Ajouter un accident". Renseignez :
  • La date et heure de l'accident
  • Si vous avez été remboursé et le montant
  • La description de l'accident
  • Les dossiers justificatifs (ordonnances, rapports médicaux...)
Formulaire de déclaration d'accident de travail
Fondation M6
5
Enregistrer une activité Fondation M6
Dans l'onglet "Fondation M6", cliquez sur "Ajouter". Renseignez l'année scolaire concernée, ajoutez des notes et joignez les fichiers justificatifs.
Formulaire Fondation M6
Crédits
6
Déclarer un crédit
Dans l'onglet "Crédits", cliquez sur "Ajouter un crédit". Cochez le type de crédit (Voiture, Immobilier, Consommation, Éducation, Autre), puis saisissez le montant total et la mensualité en MAD.
Formulaire de déclaration de crédit
4
Demandes d'absence
Soumettre une demande d'absence et suivre son statut
1
Créer une demande d'absence
Dans le menu, cliquez sur "Demandes d'absence", puis sur le bouton "Créer" en haut à droite. Le formulaire suivant s'affiche :
Formulaire de création d'une demande d'absence
2
Remplir le formulaire
Renseignez les informations suivantes :
Champ Quoi saisir
Catégorie Choisir "Absence" ou "Congé" selon votre cas
Date de début Premier jour d'absence
Date de fin Dernier jour d'absence (la durée est calculée automatiquement)
Motif Raison de l'absence (ex : Rendez-vous médical, Raison familiale...)
Professeur remplaçant Le collègue qui vous remplace pendant votre absence
Type de cours Cours théorique, Exercice, Examen, DS...
Nombre de pages Volume de cours préparé pour le remplaçant
Justificatif PDF ou image (max 5 Mo) — facultatif selon le motif
ⓘ
Cliquez sur "Créer" pour soumettre la demande, ou sur "Créer & Ajouter un autre" si vous devez soumettre plusieurs demandes.
3
Suivre vos demandes d'absence
Cliquez sur "Demandes d'absence" dans le menu pour voir la liste de toutes vos demandes avec leur statut.
Liste des demandes d'absence avec statut
Statut Signification
en attente Votre demande est soumise, en cours de traitement par la secrétaire
approuvé Votre absence est acceptée
refusé Votre demande a été refusée — contactez la secrétaire pour plus d'informations
5
Documents administratifs
Demander une attestation de travail, un certificat, une attestation salaire...
1
Créer une demande de document
Dans le menu, cliquez sur "Mes documents", puis sur "Créer" en haut à droite.
Formulaire de demande de document administratif
2
Remplir la demande
Choisissez le type de document souhaité :
Type de document Utilisation habituelle
Attestation de travail Banque, ambassade, école des enfants, dossiers administratifs
Attestation de salaire Demande de crédit, logement, administration
Certificat de travail Fin de contrat, mutation
Attestation CNSS CNSS, AMO, couverture médicale
Ordre de mission Déplacement professionnel
Choisissez ensuite le format souhaité (Version papier ou PDF numérique), ajoutez une description si nécessaire, puis cliquez sur "Créer".
3
Suivre votre demande
La liste affiche toutes vos demandes avec le type de document, le statut et le format. Quand votre document est prêt, le statut passe à approuvé.
Liste des demandes de documents administratifs
📝
Si vous avez demandé un document en format papier, vous devrez le récupérer auprès du secrétariat. Si c'est un PDF numérique, vous pourrez le télécharger directement depuis cette liste.
6
Autres demandes
Photocopies, réservation grande salle, matériel pédagogique...
1
Créer une autre demande
Dans le menu, cliquez sur "Mes autres demandes", puis sur "Créer".
Formulaire de création d'une autre demande (exemple : Photocopie)
2
Choisir le type de demande
Sélectionnez le type de demande dans le menu déroulant. Le formulaire s'adapte automatiquement selon le type choisi :
Type de demande Informations requises
Photocopie Nature du document, niveau, groupe/classe, nombre de copies, date souhaitée, fichier à photocopier
Grande salle Motif, date et horaire souhaités
Matériel Description du matériel demandé, quantité
⚠
Pour les photocopies, la demande doit être soumise au minimum 3 jours ouvrables à l'avance (week-ends exclus). Respectez ce délai pour que votre demande soit traitée à temps.
3
Suivre vos autres demandes
La liste affiche toutes vos demandes avec le type, le statut et un éventuel fichier joint.
Liste des autres demandes avec statuts variés
Statut Signification
en attente Demande soumise, en cours de traitement
approuvé Demande acceptée — vous pouvez récupérer vos photocopies / le matériel
refusé Demande refusée — contactez le secrétariat pour connaître la raison
